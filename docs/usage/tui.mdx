## What is the TUI?

The TUI is Cline's interactive terminal interface. It is designed for conversational, in-terminal work: ask questions, review plans, approve actions, and iterate quickly.

## Prerequisites

Install the CLI:

```bash
npm install -g cline
```

## Launch the TUI

```bash
# default interactive launch
cline

# explicit TUI mode
cline -i
```

## Core TUI Actions

- `Tab` to toggle Plan/Act
- `Shift+Tab` to toggle auto-approve all
- `Ctrl+C` to abort a running turn; press again to exit
- `Ctrl+D` to exit when the prompt is empty and idle
- `Ctrl+L` to clear the chat view or current conversation
- `/settings`, `/model`, `/account`, `/mcp`, `/compact`, `/context`, `/undo`, `/clear`, `/history`, `/help`, `/quit`
- `@file` mentions for workspace context

The status area shows the active model, context usage, cost, workspace/branch, git diff stats, Plan/Act state, and whether auto-approve all is enabled. Context usage is the size of the agent's last request as a share of the model's context window; when auto-compaction is on, a yellow cell in the bar marks where it starts.

## Context Usage

`/context` (or `Opt+I`) shows what the agent's last request was made of: the system prompt, rules (per rule file), memory, tools (built-in, extension, and each MCP server), and messages (conversation, tool calls, tool results, files and images, compaction summary), with the free space left and the point where auto-compaction starts. Cline estimates the split and scales it to the provider's reported input tokens, so the parts add up to the request's real size.

After a compaction the breakdown still describes the request before it until the agent sends the next one. A resumed session shows the breakdown saved with its last request.

With `--verbose`, headless runs end with the same number: `context 12,345 of 200,000 (6%)`.

## Messages While the Agent Works

Type a message and press `Enter` while the agent is working: the agent reads it at its next step, after the tool calls in progress finish. A response that is streaming is not cut off. Several messages sent this way arrive together, in the order you typed them.

- `Ctrl+S` sends the message after the run instead, as a new turn.
- Waiting messages are listed above the input. Press `↑` to select one, then `Enter` to move it to the next step or `Tab` to edit it. With an empty input, `Enter` moves the first one.
- After a Plan/Act switch, the switch stops the running turn, so messages you send before it takes effect wait and run as a new turn afterwards.

## When to Use TUI vs Headless

- Use **TUI** when you want collaboration and approvals.
- Use **headless** (`--json`, piped stdin/stdout, CI scripts) for automation.

See: [CLI Headless Mode](/usage/cli-overview#headless-mode)
